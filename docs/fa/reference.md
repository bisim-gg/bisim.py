# مرجع API

همین دلیل فقط به انگلیسی است. نام‌ها، آرگومان‌ها و رفتار همان discord.py نسخهٔ ۲ است و هر جا بی‌سیم متفاوت باشد،
همان‌جا گفته شده است.

## از کجا شروع کنم

- برای دیدن رویدادها و آرگومان‌هایشان به [Event reference](../../reference/events/) بروید.
- برای دستورهای اسلش، [Application commands](../../reference/app-commands/) و
  [Interactions](../../reference/interactions/) را ببینید.
- برای دکمه‌ها، منوهای انتخاب و فرم‌ها، [Views and components](../../reference/ui/) را ببینید.
- برای دستورهای پیشوندی، [bisim.ext.commands](../../reference/ext-commands/) را ببینید.

اگر تازه شروع کرده‌اید، از [راهنما](guide/index.md) شروع کنید.

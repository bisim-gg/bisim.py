# Interactions URL

`bisim.http_interactions` receives interactions as signed HTTP requests to your application's Interactions URL, instead of through the gateway. It needs PyNaCl: `pip install "bisim.py[http]"`. The [Interactions URL guide](../guide/topics/interactions-url.md) shows a complete bot.

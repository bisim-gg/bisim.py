# Interactions

An [`Interaction`][bisim.Interaction] is a slash command, a context menu command, a click on a button or select menu, or a submitted modal. It arrives through the gateway, or as a request to your [Interactions URL](http-interactions.md), and is answered once through `Interaction.response`, then with followups.

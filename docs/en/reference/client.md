# Client

The [`Client`][bisim.Client] connects to Bisim, keeps the cache of servers, channels, members and messages, and calls your event handlers. [`commands.Bot`](ext-commands.md) is a `Client` with prefix commands on top. The events it calls are listed in the [event reference](events.md).

# Exceptions

The exceptions the library raises. [`NotSupported`][bisim.NotSupported] is the one to know when moving from discord.py: it is raised by every feature Bisim does not have. The errors of [application commands](app-commands.md#errors) and [`bisim.ext.commands`](ext-commands.md#errors) are on their own pages.

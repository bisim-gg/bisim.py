# Embeds

Bisim shows an embed's title, description, link, colour, timestamp, author (name, link and icon), footer (text and icon), up to 25 fields, the thumbnail and the large image. A picture must be an `http` or `https` link; an `attachment://` one is kept on the object but not sent. The [Embeds guide](../guide/topics/embeds.md) walks through building one.

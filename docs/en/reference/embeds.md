# Embeds

Bisim shows an embed's title, description, link, colour, timestamp, author (name, link and icon), footer (text and icon), up to 25 fields, the thumbnail and the large image. A picture is an `http` or `https` link, or `attachment://name` for a file sent (or kept) with the same message; an `attachment://` one that names no file of the message is kept on the object but not sent. The [Embeds guide](../guide/topics/embeds.md) walks through building one.

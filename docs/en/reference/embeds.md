# Embeds

Bisim shows an embed's title, description, link, colour, timestamp, author name and link, footer text and up to 25 fields. Images, thumbnails and icons can be set and are kept on the object, but Bisim does not show them in embeds a bot sends. The [Embeds guide](../guide/topics/embeds.md) walks through building one.
